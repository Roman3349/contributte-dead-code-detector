## Usage

Extension for [shipmonk/dead-code-detector](https://github.com/shipmonk-rnd/dead-code-detector) adding support for Apitte, Contributte DI and Latte.

To install the latest version of `contributte/dead-code-detector` use [Composer](https://getcomposer.org).

```bash
composer require --dev contributte/dead-code-detector
```
